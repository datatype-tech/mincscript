# Minecraft command syntax (Java + Bedrock)

This directory is the **implementation spec** for MincScript’s Minecraft command surface. It is not a player cheat sheet. It covers the full grammar needed to parse, validate, and emit every current slash command on both editions, including `/execute` chains, selectors, SNBT/JSON, scoreboards, and inventory/data mutation.

Bedrock commands also form a **game runtime** (tick.json, scoreboard FSM, tags, `hasitem`, structure reset). See [`bedrock/gameplay/`](bedrock/gameplay/README.md) and the pack [`examples/bedrock-metro-escape/`](../../examples/bedrock-metro-escape/).

## How to implement

1. **Do not share one parser.** Java uses Mojang Brigadier (typed argument nodes + redirects). Bedrock uses a separate overloader with `name: type` arguments and `ExecuteChainedOption_0`.
2. Implement **shared lexemes** (identifiers, numbers, quoted strings, `/`) then **fork**.
3. Implement **selectors**, **coordinates**, and **execute** before any “everyday” command. Those three grammars unlock the rest.
4. For Java, treat `brigadier-tree.json` as the complete command graph. Every root command in that file must parse.
5. For Bedrock, treat the official usage lines as the complete public command set (82 commands). Education-only agent commands are out of scope unless added later.

## Cross-check rule

Every handwritten syntax line in `java/` and `bedrock/` was checked against at least two of:

1. Vanilla brigadier tree (Java)
2. Official Creator markdown / Microsoft Learn (Bedrock)
3. Minecraft Wiki Syntax sections (both)
4. Official minecraft.net command primer (chat `/`, tab complete — not a full grammar)

Conflicts: **game tree / official generator wins**. Wiki is used for argument semantics and edition tags, then re-checked against the tree or official signatures.
